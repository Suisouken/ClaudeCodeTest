# かぞくスイカゲーム 👨‍👩‍👧‍👦

フルーツの代わりに**家族の写真**で遊ぶスイカゲームです。

## 遊び方

1. `index.html` をブラウザで開く
2. 初回起動時に写真設定画面が開くので、No.1（いちばん小さい）〜 No.11（いちばん大きい）の丸をタップして家族の写真を設定する
   - 名前も自由に変更できます
   - 途中まででもOK。写真が未設定の段階はフルーツの絵文字で表示されます
3. 「あそぶ！」を押してゲーム開始
4. タップ / クリックで写真を落とし、同じ写真同士をくっつけて進化させる
5. No.11 の写真（スイカ枠）を完成させるとボーナス +100点!

写真はゲーム画面右上の「📷 写真」ボタンからいつでも変更できます。

## 写真の保存について

- 写真は選択時に 256×256 に縮小され、**この端末のブラウザ（localStorage）にだけ**保存されます
- サーバーへのアップロードは一切ありません
- リポジトリに写真ファイルは含まれないので、GitHub 上に家族の写真が公開される心配もありません

## 操作方法

| 操作 | 内容 |
|---|---|
| タップ / クリック | 写真を落とす |
| ドラッグ | 落とす位置を調整 |
| ← / → | 位置調整（キーボード） |
| スペース / ↓ / Enter | 落とす（キーボード） |

## 技術

- [Matter.js](https://brm.io/matter-js/) による2D物理エンジン
- 依存はローカルの `matter.min.js` のみ。ビルド不要、静的ファイルだけで動作します
