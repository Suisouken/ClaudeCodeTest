# かぞくスイカゲーム 👨‍👩‍👧‍👦

フルーツの代わりに**家族の写真**で遊ぶスイカゲームです。

## 遊び方

1. `index.html` をブラウザで開く（すぐ遊べます）
2. タップ / クリックで写真を落とし、同じ写真同士をくっつけて進化させる
3. No.11（スイカ枠・いちばん大きい）を完成させるとボーナス +100点!

No.1〜No.5 には `photos/` フォルダの家族の顔写真が最初から設定されています。
No.6 以降はフルーツの絵文字です。

## 写真の変更

- ゲーム画面右上の「📷 写真」ボタンで設定画面を開き、各スロットの丸をタップすると端末の写真に差し替えられます（名前も変更可能）
- 差し替えた写真は 256×256 に縮小され、**この端末のブラウザ（localStorage）にだけ**保存されます。サーバーへのアップロードはありません
- 「元の写真に戻す」で同梱のデフォルト写真に戻せます
- デフォルト写真を入れ替えたい場合は `photos/` のファイルを差し替えるか、`game.js` 冒頭の `DEFAULT_PHOTOS` を編集してください

## 操作方法

| 操作 | 内容 |
|---|---|
| タップ / クリック | 写真を落とす |
| ドラッグ | 落とす位置を調整 |
| ← / → | 位置調整（キーボード） |
| スペース / ↓ / Enter | 落とす（キーボード） |

## 技術

- [Matter.js](https://brm.io/matter-js/) による2D物理エンジン
- 依存はローカルの `matter.min.js` のみ。ビルド不要、静的ファイルだけで動作します
