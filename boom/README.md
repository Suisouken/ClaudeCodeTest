# 💥 爆発チェーンスイカ

スイカゲームの「落として合体」物理をベースに、**合体すると衝撃波で周囲のフルーツを吹き飛ばす**アレンジ版。吹き飛んだフルーツが次々ぶつかって連鎖合体すると **CHAIN コンボ**になり、得点が一気に伸びます。

## 遊び方

- **タップ / ドラッグ**で落とす位置を決め、離すと落下（PCは `←` `→` 移動・`Space`/`↓` で落下）
- 同じフルーツがぶつかると合体し、**爆発の衝撃波**で周りを押し出す
- 短時間に連続で合体すると `2 CHAIN!` `3 CHAIN!` … とコンボが増え、得点に倍率がかかる
- 点線（デッドライン）よりフルーツが積み上がるとゲームオーバー

## スイカゲームとの違い

| | スイカゲーム | 爆発チェーンスイカ |
|---|---|---|
| 合体時 | 静かに1つになる | **衝撃波で周囲を吹き飛ばす** |
| 連鎖 | なし | **CHAINコンボで得点倍率** |
| 戦略 | 積み上げ管理 | 爆発の連鎖を誘発して稼ぐ |
