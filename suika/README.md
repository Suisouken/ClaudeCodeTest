# 🍉 スイカゲーム

Matter.js を使ったブラウザ向けのフルーツ合体ゲーム。同じフルーツ同士をぶつけると、ひとつ大きなフルーツに進化します。最後の「スイカ」を目指しましょう。

## 遊び方

- **マウス / タップ**: 左右に動かして、離す（クリック）とフルーツが落ちます
- **キーボード**: `←` `→` で移動、`Space` / `↓` / `Enter` で落下
- 同じフルーツがぶつかると合体して進化します
- 点線（デッドライン）よりフルーツが積み上がるとゲームオーバー

## 起動

`suika/index.html` をブラウザで開くだけです（外部依存は CDN の Matter.js のみ）。

オフラインや簡易サーバーで動かす場合:

```bash
cd suika
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 構成

- `index.html` — 画面・スタイル・HUD
- `game.js` — ゲームロジック（物理・合体・スコア・入力）
